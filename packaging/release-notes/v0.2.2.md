Plugg 0.2.2 fixes Arturia Software Center, which 0.2.1 did not.

This is still a developer preview. It works on the maintainer's system (CachyOS, Hyprland, Bitwig) with the vendors in the [compatibility notes](https://github.com/oikoaudio/plugg/tree/v0.2.2/docs/compatibility). Not every plug-in will work.

## Install

- Ubuntu 24.04 or newer, Debian 13 or newer: download `plugg_0.2.2_amd64.deb` below, then `sudo apt install ./plugg_0.2.2_amd64.deb`
- Fedora 42 or newer: download `plugg-0.2.2-1.x86_64.rpm` below, then `sudo dnf install ./plugg-0.2.2-1.x86_64.rpm`
- Arch and Arch-based systems: download `plugg-0.2.2-1-x86_64.pkg.tar.zst` below, then `sudo pacman -U ./plugg-0.2.2-1-x86_64.pkg.tar.zst`

To update from 0.2.1 or 0.2.0, install the new package over the old one. Your library and the plug-ins already in your DAW stay as they are.

## Arturia

- Arturia Software Center crashed in Wine's UI Automation while it synchronized licences after signing in automatically. 0.2.1 tried to turn UI Automation off for it, but too late in the launch to take effect. Plugg 0.2.2 turns it off before Proton starts, for the Software Center and the installers it runs. Arturia's plug-ins already had this in 0.2.1.
- An Arturia environment made with 0.2.1 keeps its old launcher. [The Arturia notes](https://github.com/oikoaudio/plugg/blob/v0.2.2/docs/compatibility/arturia.md#existing-installations) say how to fix it by hand.

## Plugg has no helpdesk

One person makes Plugg. Good bug reports get read and fixed. To send one, open Help in the app and choose Report a bug in Plugg. The form asks for what makes a report useful. A request to get one particular setup working usually can't be answered.

## Files

- `.deb`, `.rpm` and the generic tarball hold the app, the prebuilt plug-in bridge and the PowerShell forwarder. The bridge needs glibc 2.34 or newer.
- The Arch package holds the same app, with a bridge compiled on Arch from the same tag.
- `plugg-bridge-0.2.2-x86_64.tar.gz` is the bridge on its own, with its licences.
- The wheel is the Python package. Installed with pipx, it downloads the bridge above on first use.
- `SHA256SUMS` lists every file's checksum.
