Plugg 0.2.1 adds Arturia Software Center and fixes deleting and cleaning up environments.

This is still a developer preview. It works on the maintainer's system (CachyOS, Hyprland, Bitwig) with the vendors in the [compatibility notes](https://github.com/oikoaudio/plugg/tree/v0.2.1/docs/compatibility). Not every plug-in will work.

## Install

- Ubuntu 24.04 or newer, Debian 13 or newer: download `plugg_0.2.1_amd64.deb` below, then `sudo apt install ./plugg_0.2.1_amd64.deb`
- Fedora 42 or newer: download `plugg-0.2.1-1.x86_64.rpm` below, then `sudo dnf install ./plugg-0.2.1-1.x86_64.rpm`
- Arch and Arch-based systems: download `plugg-0.2.1-1-x86_64.pkg.tar.zst` below, then `sudo pacman -U ./plugg-0.2.1-1-x86_64.pkg.tar.zst`

To update from 0.2.0, install the new package over the old one. Your library and the plug-ins already in your DAW stay as they are.

## Arturia

- Drop the Arturia Software Center 2.12.0.3157 installer on the window. Plugg sets up an environment for it, and you sign in and install your products from the Software Center.
- Wine's UI Automation crashed both the Software Center, while typing in its login fields, and Arturia's plug-ins, when an editor window closed. Plugg turns it off for the Software Center and for Arturia's plug-in hosts. Screen readers get no information from them.
- Delay TAPE-201, Jun-6 V and Tape MELLO-FI were checked in Bitwig. The [Arturia notes](https://github.com/oikoaudio/plugg/blob/v0.2.1/docs/compatibility/arturia.md) have the details.

## Deleting environments

- An environment whose plug-in session is idle can be deleted right away. Before, deletion was refused for five minutes after the last plug-in closed. Running Windows programs still block deletion, and the dialog names them.
- A protected environment that holds only unlicensed products can be deleted from the app. Before, every attempt failed after the phrase was typed.
- When an environment's licence record can't be read, the delete dialog says so before you type anything, with the command that shows why.
- The delete dialog counts the environment's licensing recovery points and says they are deleted with it, and how to keep them.

## Fixes

- A plain installer that fails before it runs, for example while Proton downloads, no longer leaves its environment behind. A cancelled one is cleaned up too.
- The runtime selected for new environments is never offered for reclaim. Reclaiming it broke the next setup.
- The docs and the delete dialog no longer call a lost iLok activation permanent. iLok License Manager can report a lost computer as unusable from another machine, and each publisher decides whether to return the activations. Deactivating first is still the quick way. The [PACE notes](https://github.com/oikoaudio/plugg/blob/v0.2.1/docs/recipes/pace.md) have the steps.

## Plugg has no helpdesk

One person makes Plugg. Good bug reports get read and fixed. To send one, open Help in the app and choose Report a bug in Plugg. The form asks for what makes a report useful. A request to get one particular setup working usually can't be answered.

## Files

- `.deb`, `.rpm` and the generic tarball hold the app, the prebuilt plug-in bridge and the PowerShell forwarder. The bridge needs glibc 2.34 or newer.
- The Arch package holds the same app, with a bridge compiled on Arch from the same tag.
- `plugg-bridge-0.2.1-x86_64.tar.gz` is the bridge on its own, with its licences.
- The wheel is the Python package. Installed with pipx, it downloads the bridge above on first use.
- `SHA256SUMS` lists every file's checksum.
